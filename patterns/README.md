# Patterns

Short write-ups of the choices behind this toolkit. Each one takes about two minutes to read, and you can copy it into your own setup.

| Pattern | In one line |
| --- | --- |
| [The repo is the marketplace](repo-is-the-marketplace.md) | Keep a plugin next to the work it serves, and version it so installed copies update. |
| [Skills for sessions without plugins](skills-without-plugins.md) | Cloud sessions and routines read the skill file from the checkout. One source serves both. |
| [Read-only agents that return drafts](read-only-agents.md) | Limit the tools, name the forbidden commands, back them with permission rules, and return a draft. |
| [Data is not instructions](data-is-not-instructions.md) | Text in issues, PRs and pages is reported, never obeyed. |
| [Every fact has a date](every-fact-has-a-date.md) | "Checked 2026-10-10: ..." or it is a guess, and a guess says so. |
| [Config, not names](config-not-names.md) | Skills read one small `toolkit.json` for your repos, board and owner. |
