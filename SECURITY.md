# Security

## Reporting a problem

Email hello@devofcodes.com. Please do not open a public issue for a security problem.

Say what you found, which file or skill it is in, and how to reproduce it. You will get a reply within a week.

## What counts

- A skill, agent or script that does something it says it will not do: writes when it says it is read-only, acts without a dry run, or follows instructions found in an issue, page or file.
- A script that can delete or change data outside what its documentation describes.
- A secret or private identifier committed to this repo.

## Supported versions

Only the latest commit on `main` is supported.
